Xenachord Designer · Cimbalo Cromatico

Spine, feet and every dimension are inferred from Cimbalo_Cromatico_Drafting_Sandbox_Leveling.blend. Start from 32 plain whites and drag key types into the gaps between them.

Keyboard

32 keys, always. One AKM320 — spine half A and half B, 16 sensor feet each. Drop a key into a gap and whites come off the right-hand end to pay for it; everything then re-widens so the keyboard still ends exactly at the spine.

Key Type Categories — drag these

Every chip is drawn at one width; the real width comes from the keyboard when it lands. A split pair is one component — it drops both halves, and clicking either half removes both.

The ends are gaps too. There is a target before the first white and one after the last, so a keyboard can begin or end on an accidental. An end gap has a white on one side only, so that white grows outward to stand under it — the accidental keeps its place in the pitch and the deck runs unbroken to the edge of the mount instead of finishing on a floating key.
