Xenachord Designer · Cimbalo Cromatico

Spine, feet and every dimension are inferred from Cimbalo_Cromatico_Drafting_Sandbox_Leveling.blend. Drag a Key Type Category into a slot to build a layout.

Layout

32 keys, always. One AKM320 — spine half A and half B, 16 sensor feet each. The white-key count is derived from the pattern, never chosen.

Widths follow the sheet's size law: white = s×1.5416667, accidental = s×0.6916667, slot bias δ = s/6, white gap 1.5 mm.

Key Type Categories — drag these

All seven chips are shown at one width. The real width is taken from the layout when the key is dropped. Click a placed key to remove it.
